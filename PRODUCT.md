## Gemini question engine

Online Brain Duel uses a private host lobby. The host chooses a remembered topic or sanitized custom topic, Easy/Medium/Hard difficulty and 3/5/10 questions. The guest sees the host-chosen summary and joins explicitly. Both players must be present and ready; changing setup clears both ready checks. Server presence expires after 20 seconds, and the server checks readiness before generation, before starting the match and before accepting trivia moves. The existing GameSurface handles paired reveals, scores and reporting.

New online trivia matches use unseen AI bank questions only, with no fallback trivia. A shared generation lease prevents duplicate batches; generated extras remain available for later games. Private match snapshots keep correct indices and fun facts sealed until paired reveal, with server scoring and reporting to retire bad questions. Per-couple normalized history prevents exact reuse, and generation filters close paraphrases against recent topic history. Preview remains fixture/local pass-and-play and does not use this online lobby.

Daily questions and Would You Rather use a shared batch of 30 daily prompts and 30 pairs assigned in the saved couple timezone. Authenticated app open tops up a runway below seven days or tries to promote saved non-AI content when AI is enabled. A shared claim limits these content attempts to once an hour. AI can replace an unanswered fallback prompt; a prompt with either player's answer is preserved. Saved prompts still fill content gaps when generation is unavailable. Settings > AI Questions exposes configuration presence, model, UTC usage, safe errors, bank counts, content runway, an AI toggle, timezone and guarded refill. No Gemini key or private personal content is sent through the UI or included in generation prompts.

The default model is `gemini-3.5-flash-lite`. Real calls use server-only credentials, global atomic caps of at most four attempts/minute and sixty/day, one delayed fallback model and a ten-minute circuit breaker. Development, hot reload, CI and automated tests use fixtures; the manual `gemini:check` command is the only local live-call path. The existing seed bank contains 150 stable trivia items, 100 daily prompts and 100 pairs; online trivia excludes fallback items. See GEMINI_SETUP.md.
