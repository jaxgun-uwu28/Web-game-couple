# Gemini questions setup

1. In Supabase SQL Editor, run `supabase/migrations/009_ai_questions.sql` after migration 008. It adds the private bank, match question snapshots, history, generation leases, budgets, content packs and saved timezone. Existing in-flight trivia packs remain playable.
2. Create an API key at https://aistudio.google.com/apikey. Use a project marked **Free** without a linked billing account. The API does not provide an application flag that can force a paid project onto the free tier. This app caps itself at at most 4 attempts/minute and 60/day; Google may enforce lower limits. Quotas are project/model dependent, and switching keys in the same project does not create extra quota.
3. Add `GEMINI_API_KEY` in `.env.local` for the manual check and in Vercel's server environment for production. Keep `SUPABASE_SERVICE_ROLE_KEY` in the server environment too. Neither variable may use `NEXT_PUBLIC_`. Redeploy Vercel after changing variables. The APK uses your existing HTTPS origin; no Gemini key goes in Android files.
4. Copy the optional Gemini settings from `.env.example`. The default is `gemini-2.5-flash-lite`, with `gemini-2.5-flash` as an optional single fallback. Check the model's current Free-plan availability in AI Studio; model names and quotas can change. Disable AI or remove the key to use saved content.
5. Run `npm run gemini:check` manually when ready. This is the **only local live-call command**: one tiny request, no retries, no key logging. Its response is saved under ignored `.cache/gemini/`. I have not run it. Development, hot reload, CI and `npm test` use fixtures even if a real key is set.
6. Open **Us → AI Questions**. Check configuration, UTC request count, shared timezone and saved content runway. “Refill now” tops up only below seven days; repeatedly pressing it does not buy extra packs or bypass caps. The daily pack is prepared lazily on the first authenticated app open, with a shared lease; no cron is required.

## Behavior

A new online duel checks unseen, unflagged bank entries before generation. One batch requests the selected 3/5/10 questions plus up to five extras; extras stay in the bank. The first phone owns the lease, the other listens for completion and joins the same game. A 15-second client timeout switches to saved content without triggering a second AI call. Atomic SQL match creation and per-couple normalized-stem history protect against simultaneous reservation and exact repeats. The generator additionally compares the last 40 topic stems for close similarity. Questions and options are copied into match state; correct indices and fun facts stay in the private snapshot until both answers reveal. Reports retire a bank entry from future use.

The fallback contains 150 original stable trivia items across the topic groups, 100 daily prompts and 100 pairs. A missing/blocked/invalid API uses saved items; a custom topic may fall back to a saved general mix, visibly labeled. Finite trivia seeds cannot provide an unlimited lifetime of unseen questions while AI is unavailable: when the unseen pool is exhausted, reconnect AI to refill it. Daily packs avoid their last 30 stems/pairs and can rotate the saved collection after that window. Existing answered dates are never overwritten.

Every real model attempt reserves the shared SQL budget before sending, including a fallback attempt. A 429/503/404 can try one configured fallback after delay/jitter and Retry-After, within a 12-second request deadline. Long Retry-After periods fall straight back to saved questions. Three failures pause AI for ten minutes. Invalid/filtered responses do not cause repair requests; valid items are kept and gaps use saved content. Only safe error summaries are stored; model response bodies, prompts, keys and personal data are never logged. Prompts contain content-only history, topic, count and difficulty; personal answers, profiles, notes, media and dates are never sent.

Official references: [Free-plan billing](https://ai.google.dev/gemini-api/docs/billing), [rate limits](https://ai.google.dev/gemini-api/docs/rate-limits), [structured output](https://ai.google.dev/gemini-api/docs/structured-output).
