# Our Little Arcade

A love letter on the table of a little forest cabin. The window is a photographic anchor; the playable objects are cream paper, ink, board-game pieces and olive bookcloth. Asymmetric compositions and handwritten marginalia keep the place intimate. The product is a private shared space for Lance and Elaine, not a marketing page.

## Palette

Paper #F5F0E4, ink #262821, forest #344F3F, light leaf #DCE7CE, wine #713A45, rose #E8C8C8, brass #806132. Elaine owns the green circle; Lance owns the black cross. Text uses ink/forest on paper and paper on forest; secondary text #626653. Night uses #171F1B with text #F5F0E4. Colored game pieces always include symbols.

## Type and rhythm

Fraunces for expressive serif headings, DM Sans for readable controls, Caveat for short personal notes. Google Fonts, SIL Open Font License; Georgia and system sans fallbacks. Spacing scale 4, 8, 12, 16, 24, 32, 48, 72px. Fluid headings and generous separation between objects; 44px minimum controls. No card grid or stock dashboard chrome.

## Motion and environment

One authored moment: a paper-turn entry into a game. Other controls use 160ms ease-out. Respect reduced motion. A cabin window changes tint for morning, golden hour, dusk and night. Northern-calendar seasonal label is decorative, not a claim about Philippine weather. Weather is opt-in; ambient sound is generated Web Audio, off by default. No autoplay.

## Assets

Self-hosted forest photograph from Unsplash, license Unsplash (see CREDITS.md). Lucide icons under ISC. Original favicon geometry. Google Fonts above. The setting is a forest cabin: no competing scenery. No emoji as UI decoration.

## Surface behavior

Login is a personal invitation with password and magic-link choices. After login the home table contains a live game invitation, rivalry ribbon, daily question and activity notebook. Selecting a game opens an inline work area. Personal information never appears on a publicly accessible preview; the preview uses only supplied names and preferences and cannot persist data.
